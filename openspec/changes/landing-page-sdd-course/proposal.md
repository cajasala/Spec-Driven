## Why

Necesitamos una landing page principal para generar expectativa sobre el nuevo curso de "Spec Driven Development". Esto resolverá el problema de no tener un punto de entrada para captar el interés de potenciales estudiantes y vender el curso efectivamente, ya que actualmente la aplicación base de React está vacía.

## What Changes

- Creación de una página de inicio (Landing Page) atractiva y moderna.
- Secciones de hero (título, subtítulo, botón de acción), beneficios del curso, currículo/contenido general y call-to-action (CTA) para inscripción o lista de espera.
- Integración del diseño base utilizando React.

## Capabilities

### New Capabilities
- `landing-page-sdd`: Define los requisitos, estructura y contenido principal de la landing page del curso para Spec Driven Development.

### Modified Capabilities

## Impact

- Se modificará `App.jsx` y `index.css`/`App.css` para implementar la nueva página.
- Creación de nuevos componentes de interfaz de usuario para la landing page.
- Modificación del diseño global del proyecto y de los estilos base.
