## ADDED Requirements

### Requirement: Curriculum Component Updates
El sistema SHALL mostrar un plan de estudios que integre explícitamente módulos sobre OpenSpec y Antigravity.

#### Scenario: Displaying updated modules
- **WHEN** el usuario navega a la sección del currículo
- **THEN** verá módulos detallando la creación de propuestas con OpenSpec y el desarrollo agéntico con Antigravity.
