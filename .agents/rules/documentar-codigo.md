# Regla: Contenido en Español Obligatorio

## Contexto
Este proyecto está dirigido a usuarios hispanohablantes. Todo el contenido visible debe estar en español.

## Directivas
1. **Interfaz de Usuario**: Todo el texto en botones, menús, títulos y párrafos debe generarse exclusivamente en español neutro.
2. **SEO y Accesibilidad**: Las etiquetas `alt` de las imágenes y las meta-descripciones deben estar en español.
3. **Atributo HTML**: Asegúrate de que el archivo principal siempre incluya `<html lang="es">`.
4. **Comentarios de Código**: (Opcional) Genera los comentarios del código también en español para mantener la coherencia.

## Excepciones
- Mantener términos técnicos de programación en inglés si es el estándar de la industria (ej. nombres de variables, funciones de API, Spec Driven Development).
